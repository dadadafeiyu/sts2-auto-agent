# QQ 播报（可选）

本目录说明如何把「局末总结 / 聊天播报 / 截图发到 QQ」接上。

## 它做什么

| 能力 | 说明 |
|---|---|
| 局末播报 | 一局结束后发一段总结到指定会话 |
| 截图 | 结算时抓一张游戏画面一起发 |
| 实时指挥 | QQ 里说「杀戮尖塔 开一把 / 接着玩 / 保存退出」来控制 |

## 依赖

需要一个能调用 `chat.send` / `chat.send-image` 的宿主（本项目的参考实现基于 DeepSeek Harness 的 QQ 插件）。
**没有宿主也能玩**，只是没有播报。

## 触发词（严格模式）

必须带上「杀戮尖塔」或「sts2」，避免误触发：

| 你说 | 发生什么 |
|---|---|
| 杀戮尖塔开一把 | 开新局 |
| 接着玩杀戮尖塔 | 继续存档 |
| 杀戮尖塔保存退出 | 保存并关游戏 |

只写「继续玩」「保存退出」**不会**触发。

## 接入方式

1. 把 `decider/index.js` 装成宿主的 skill/plugin
2. 在宿主里配置决策服务的端口（默认 18731）
3. 宿主要有 `chat.send`、`chat.send-image` 两个 capability
